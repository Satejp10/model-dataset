# Dataset Change Logs

This folder tracks every change made to `Pruned AI Models_Table.xlsx`.

## How to use

- Record each change in `CHANGELOG.md`, newest entry at the top.
- For every entry note the **date**, **what changed** (models added / removed / edited,
  columns changed, corrections), and **who/why** if relevant.
- When models are added, list them with their `Model` and `Lab`.
- After a batch of edits, update the **Current dataset specs** section in `CHANGELOG.md`
  (row count, column count, number of models, number of labs) so the latest snapshot
  is always visible at a glance.

## Files

- `CHANGELOG.md` — reverse-chronological log of changes, plus a live specs snapshot.
